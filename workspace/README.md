# Internal Workspace

This folder collects personal working notes for navigating and extending the WalkTheWeb codebase.  It is not part of the runtime application; it exists purely as a developer knowledge base with repository maps, architecture breakdowns, and focused reference sheets.

## Contents
- `repo-map.md` — directory-level overview of the codebase.
- `architecture.md` — execution flow and platform architecture notes.
- `function-notes.md` — focused details on frequently touched classes and helper APIs.
- `handlers-and-endpoints.md` — quick reference to HTTP entry points and service connectors.

Feel free to append additional notebooks or scratch documents while working; this workspace is intentionally flexible so it can grow with your understanding of the project.
